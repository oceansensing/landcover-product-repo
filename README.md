# landcover-product-repo

The world's land cover at 10 m, ESA WorldCover 2021, as map tiles for the
oceansensing.org ocean map: each pixel one of its eleven classes, in ESA's own
colors.

Checked daily; the source is final, so the tiles change only if it does.
